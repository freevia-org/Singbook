## Scope and limitations

This review covers the tracked baseline and the resulting fixes, rather than
every historical worktree, ignored credential file, user database, private QA
packet, build cache, or another owner's unfinished canonical changes. No live
account/Drive operation, device installation, signed release, or store update is
part of these fixes. The application version remains `0.2.14+28`.

Host tests and source review do not establish full Android/iOS/Windows GUI,
hardware/DPI, provider-availability, or live-account parity. Existing native QA
limitations and immutable release evidence remain unchanged. No review can
guarantee the absence of every remaining defect.
