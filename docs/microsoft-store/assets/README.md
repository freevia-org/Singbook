# Singbook Microsoft Store poster

`poster-9x16.png` is **marketing poster art, not an app screenshot**. Partner Center's English listing uses it in the **9:16 Poster art** field in published Submission 16. The Windows package remains `Singbook_1.0.46.0_x64.msix`; adding the file to this repository did not change the Store listing or package by itself.

| `poster-9x16.html` | Editable HTML/CSS source at a fixed 1440 × 2160 canvas. |

The composition uses the existing [Singbook icon](../../../assets/branding/singbook-icon.png) unchanged. Its [provenance record](../../../assets/branding/singbook-mark-provenance.json) is in this repository. Typography uses the existing [Singbook Serif font](../../../assets/fonts/SingbookSerif-Bold.ttf), covered by its [SIL Open Font License notice](../../../assets/fonts/SingbookSerif-OFL.txt). The CSS adds navy, blue, parchment and amber backgrounds and the benefit copy “Lyrics. Chords. Setlists.” It does not depict an interface, include song lyrics or personal data, or use Microsoft marks.

Prepared and visually inspected on 29 October 2026. The PNG was rendered from the HTML at 1440 × 2160 in Chrome, then checked at full size and at a 240 × 360 card reduction. It has no clipping; the brand and core benefits remain legible at small size. Submission 16 published the poster as a **listing-only** change, keeping the same MSIX and four genuine Windows workflow screenshots in their separate screenshot slots.
