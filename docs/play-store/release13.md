# Release 13

Version 0.2.0+13 consolidates the approved Home/header/menu/About changes and
player control improvements. It retains release 12 cloud-sync and privacy
behavior. The header uses the requested generic account icon; the account
section still displays the connected profile photo when available.

Preserve saved app-access credentials, all five existing internal testers,
and the production selection of 178 regions. Do not change data-safety
answers or privacy hosting solely for these UI changes.
