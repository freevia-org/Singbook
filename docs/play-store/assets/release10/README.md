# Release 0.2.0 (10) phone screenshots

These are native Android emulator captures of the accepted release 10 Flutter
runtime (`3d7deb5`, integrated as `3d87eb4`), using the original fictional
Lanterns at Dawn / The Paper Moons fixture. They contain no third-party lyrics.

All four PNGs are 1080 x 1920 (9:16), with the device status and navigation bars
included. The pixels are unchanged after capture.

- `store01_search.png`: song search result with artist, album and duration.
- `store02_versions.png`: horizontal version tabs and combined-source contributions.
- `store04_full_preview.png`: full lyrics/chords preview and Save & open lyrics.
- `store05_reader.png`: saved song, chords, comparison access and scrolling controls.

These replace the earlier phone captures for the Google Play release 10 listing.
The parent directory retains older reference captures. The capture-only harness
and native test log are kept in the local release artifacts; they are not compiled
into the signed release application.
