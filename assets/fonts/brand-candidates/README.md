# Brand font assets

`SingbookSerif-Bold.ttf` is a metadata-renamed static instance of the official Google Fonts Lora variable font at weight 700. Its glyph-outline tables are byte-for-byte identical to the original derived instance; the family metadata uses the neutral name “Singbook Serif” to honor Lora's Reserved Font Name. The SIL Open Font License and copyright attribution are retained in `../SingbookSerif-OFL.txt`; source provenance is documented in `Lora-OFL.txt`.

`Bitter-Bold.ttf` remains a visual-comparison candidate and is not registered in `pubspec.yaml`; its OFL notice is `Bitter-OFL.txt`.
